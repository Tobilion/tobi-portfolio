Welcome to the repository for my personal developer portfolio website. This platform serves as my digital showroom, engineered to demonstrate software architecture principles, clean component design, and elegant user experiences.

---

## 🌌 The Design Aesthetic & Blueprint

The portfolio breaks away from traditional layouts, adapting a highly polished, interactive framework:

- **The Vibe:** Premium, ultra-dark mode backdrop (`#0a0a0a`) layered with frosted glassmorphic cards and radiant, neon blue/purple ambient hover states.
- **The Core Focus:** Tailored for a deep-dive into software development, robust back-end logic, computer architecture, and active open-source contribution.
- **Interactive 3D Elements:** Features an integrated interactive 3D tech canvas embedded directly inside the Hero viewport.

---

## ⚡ Key Features

🎮 **Bento-Box Grid** An elegant modular card interface detailing my languages, frameworks, and core technical proficiencies.

🌍 **Bilingual & Layout Framework Toggle (LTR / RTL)** A fully dynamic internationalization toggle (English/Arabic) built right into the sticky navbar that seamlessly flips the layout grid configuration to support Right-to-Left structural rendering.

🚀 **Filterable Projects Hub** An active, searchable repository browser embedded into the UI where recruiters can filter live projects by language tag pills (e.g., Python, Java, C++).

⏳ **Dynamic Academic Timeline** A clean vertical course timeline tracking my progressive computer science milestones, theoretical explorations, and core technical preparation.

🟢 **Real-Time Availability Dot** An live pulsing indicator at the top of the viewport marking my active availability for software collaboration and new project opportunities.

---

## 🛠️ Technical Stack Breakdown

### Front-End Foundations

- **Framework:** React.js (Bootstrapped with Vite)
- **Styling:** Tailwind CSS (Utilitarian utility grids & glassmorphism details)
- **Animations:** Framer Motion (Staggered card entries, smooth layout scrolls, and glowing border interactions)
- **3D Graphics:** Spline / Three.js (Interactive abstract core graphics)

### Core Expertise Represented

- **Languages:** Java, Python, C++
- **Systems Engineering:** Computer Systems Architecture, Digital Logic Pipelines, CPU Pipelining
- **Developer Ecosystem:** Git, GitHub, VS Code, Vercel
