# AGENTS.md

Personal portfolio site for Tobiloba Jagun. Deployed on Vercel: https://tobiloba-jagun-portfolio.vercel.app/

## Stack

- React 19 + TypeScript (mixed TS/JS, `allowJs: true`, strict mode) on Vite 8
- Tailwind CSS v4 via `@tailwindcss/vite` plugin (no tailwind.config file — v4 CSS-first config in `src/index.css`)
- Framer Motion (animations), Lenis (smooth scroll), Spline (`@splinetool/react-spline`, 3D hero canvas)
- Radix Slot + CVA + clsx/tailwind-merge (shadcn-style UI utilities in `src/lib/utils.ts`)
- EmailJS (contact form, browser-side)
- ESLint 10 flat config

## Folder structure

```
src/
  App.tsx, main.tsx        entry
  animations/variants.ts   shared Framer Motion variants
  components/
    layout/                Navbar, Footer
    sections/              Hero, About, Skills, Projects, Experience, Blog, GitHubActivity, Contact
    ui/                    reusable widgets (splite.tsx = Spline wrapper, tubelight-navbar, etc.)
  constants/portfolioData.ts   all portfolio content/data lives here
  hooks/                   useSectionInView.js, useTextScramble.ts
  lib/utils.ts             cn() helper
  types/global.d.ts
```

Path alias: `@/*` → `src/*` (set in vite.config.js, tsconfig.json, and jsconfig.json).

## Commands

- `npm run dev` — dev server
- `npm run build` — production build (no tsc step; run typecheck separately)
- `npm run typecheck` — `tsc -p tsconfig.json` (noEmit)
- `npm run lint` — eslint
- `npm run preview` — preview built dist
- `push-portfolio.bat` — Windows helper: clears stale `.git/index.lock`, stages, commits, pushes (commit message is hardcoded — edit before use)

## Env

EmailJS credentials in `.env` (see `.env.example`): `VITE_EMAILJS_SERVICE_ID`, `VITE_EMAILJS_TEMPLATE_ID`, `VITE_EMAILJS_PUBLIC_KEY`. Must also be set in Vercel project settings.

## CV

`public/Tobiloba_Jagun_CV.pdf` has no source doc (no docx/Google Doc) — it's generated by a one-off reportlab script (Helvetica, one page, letter size, ~9pt body). To edit content, regenerate the PDF with reportlab rather than editing it directly, and keep the "Software Projects" section in sync with `PROJECTS` in `src/constants/portfolioData.ts`.

## SEO

Canonical domain is `https://tobiloba-jagun-portfolio.vercel.app/` (matches `index.html` canonical/OG tags, `public/robots.txt`, `public/sitemap.xml`, and JSON-LD Person schema in `index.html`). Fixed 2026-07-11: these previously pointed to `tobi-portfolio.vercel.app`, an unrelated third party's old portfolio site — search engines were being told the canonical URL was someone else's site, which suppressed indexing. If the Vercel domain or a custom domain ever changes, update all four of those locations together.

## Gotchas

- No `ErrorBoundary` existed at the app root or around lazy sections — any uncaught render error anywhere blanked the entire page (React unmounts the whole tree on an uncaught error with no boundary). Fixed 2026-07-10: added `src/components/ui/ErrorBoundary.tsx`, wrapped `Hero`'s `SplineScene` (falls back to `/Images/hero-3d.jpeg`) and every lazy section in `App.tsx`. If a "white screen after ~3s" recurs, check the browser console first — the ~3s delay lines up with `SplineScene`'s `requestIdleCallback`/`setTimeout` mount trigger in `src/components/ui/splite.tsx`, so Spline/WebGL failures are the prime suspect.
- `vite.config.js` `manualChunks` is a **function**, not an object — required by Rolldown (Vite 8's bundler). Don't convert back to object form.
- Tailwind v4: no `tailwind.config.js`; theme/customization goes in CSS. Don't add v3-style config.
- Mixed .js/.ts codebase — new files should be TypeScript; `useSectionInView.js` remains JS.
- `.git/index.lock` gets stale on Windows sometimes (hence the .bat cleanup step).
- Site supports LTR/RTL (English/Arabic) toggle — layout changes must work in both directions.
- Dark-mode default (`#0a0a0a` backdrop); respects OS preference.
- Lazy sections in `App.tsx` used `<Suspense fallback={null}>`, which rendered zero height while chunks downloaded. For the first few seconds after load this made the page only as tall as Hero (nothing below was scrollable), and it made `tubelight-navbar.tsx`'s scroll-spy "reached bottom" check (`scrollY + innerHeight >= scrollHeight - 120`) fire immediately, lighting up "Contact" as active. Fixed 2026-07-20: added a `SectionFallback` (`min-h-screen` placeholder div) as the fallback for every lazy section so layout height is reserved from first paint.
